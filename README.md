# Propagaluz

A foundation based in Madrid, raising funds for the education of underprivileged Venezuelan children and championing the freedom of speech of Venezuelans, young and old. Propagaluz means *spread light*.

This repository is the foundation's source of truth. Every session, every decision, every piece of copy and every page of the site refers back to the files at the top of this folder.

## Where to start
- **`PRODUCT.md`** — what propagaluz is and how it works.
- **`BRAND.md`** — voice, language rules, decide-don't-ask sheet.
- **`LEGACY.md`** — the family DNA (internal).
- **`DECISIONS.md`** — log of decisions and reasons.
- **`OPEN_QUESTIONS.md`** — what is still unresolved.
- **`DESIGN.md`** — visual direction (populated after the visual round).

## Folder map
- `assets/` — logo, photography, visual references.
- `research/` — outputs of research by topic (`legacy/`, `ecosystem/`, `legal/`, `peers/`).
- `content/` — the manifesto and page-by-page copy.
- `web/` — the Next.js codebase (created once we move to build).

## Working with this project
1. New session: read `PRODUCT.md` and `BRAND.md` before anything else.
2. Decision made: log it in `DECISIONS.md` with the reason.
3. Question left open: capture it in `OPEN_QUESTIONS.md` with context.
4. New research: write it into `research/<topic>/` and reference it from the relevant top-level file.

Every gesture from propagaluz is deliberate. This file is no exception.
